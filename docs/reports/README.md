# Validation Reports

Reports are dated records of what repository tooling and integration paths
actually did. They preserve the environment, commands, evidence, limitations,
and follow-up asks from a particular run; they are not statements of timeless
architecture or future design.

| Series | Scope |
| --- | --- |
| [OpenStrata dogfooding](ost/) | Build, test, packaging, runtime, and host-environment behavior observed while using `ost`. |
| [2026-10-20 Physics scene full rebuild](2026-10-20-physics-scene-rebuild.md) | Local Windows consumer-owned rebuild, rollback, joint execution and installed API verification. |
